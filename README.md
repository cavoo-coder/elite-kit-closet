# Elite Kits Showcase

Create a complete, premium, modern and mobile-responsive e-commerce website for my football jersey business called ELITE KITS.

BUSINESS INFORMATION

* Business name: ELITE KITS
* Business type: Football/sports jerseys and kits
* Location: Tanzania
* Phone/WhatsApp: 0617304403
* Instagram: @ELITE_KITS
* Main goal: Sell football jerseys online, attract customers, showcase available kits, and make it extremely easy for customers to contact/order.

BRAND STYLE

Make the website look luxurious, elite, clean, powerful and sporty, like a premium football fashion brand.

Use a sophisticated dark/black theme with strong contrast and premium typography. The design should feel expensive and professional, not like a cheap template.

Brand personality:

* Elite
* Premium
* Football culture
* Confident
* Modern
* Stylish
* Trustworthy

Use subtle animations, smooth scrolling, elegant hover effects and professional spacing. Do not overdo animations.

WEBSITE STRUCTURE

1. HERO SECTION

Create a visually impressive homepage hero section.

Headline:
WEAR THE GAME. LIVE THE LEGACY.

Subheading:
Premium football jerseys and kits for those who don’t just watch the game — they live it.

Buttons:

* SHOP JERSEYS
* ORDER NOW

Include a premium football jersey visual in the hero section.

Add a small trust statement such as:
Premium Football Jerseys • Tanzania

Create a sticky navigation bar containing:

3. SHOP / JERSEYS SECTION

Create a professional product catalogue.

Each jersey card should display:

* High-quality product image

Include categories/filters:

* Football Kits

Add sorting options:

* Newest
* Price: Low to High
* Price: High to Low

Make the product catalogue easy to update later.

4. PRODUCT DETAILS

When a customer clicks a jersey, open a professional product page/modal containing:

* Large product photos
* Product name
* Price
* Description
* Available sizes: S, M, L, XL, XXL
* Quantity selector
* Add to Cart

DESIGN REQUIREMENTS

The website must:

* Look premium and expensive
* Be fully responsive on iPhone, Android, tablet and desktop
* Have excellent mobile navigation
* Load quickly
* Have smooth animations
* Use high-quality football jersey imagery
* Have clear call-to-action buttons
* Use excellent typography
* Have strong visual hierarchy
* Avoid clutter
* Avoid excessive gradients
* Avoid generic stock-template appearance
* Have professional spacing and alignment

Make the website feel like a real established football fashion brand.

SEO

Optimize the website for searches related to:

* football jerseys Tanzania
* football kits Tanzania
* football jerseys Dar es Salaam
* affordable football jerseys Tanzania
* football shirts Tanzania
* ELITE KITS Tanzania

Add appropriate page titles, meta descriptions, image alt text and semantic HTML.

TECHNICAL REQUIREMENTS

Build the actual working website, not just a visual mockup.

Use a clean modern architecture and reusable components.

Make the products easy to edit later.

Do not hard-code the entire catalogue into one huge component.

Create reusable components for:

* Navbar
* Hero
* ProductCard
* ProductGrid
* ProductDetails
* Cart
* Categories
* Testimonials
* FAQ
* Contact
* Footer

Ensure buttons, navigation, filters, cart interactions and WhatsApp ordering actually work.

Before finishing, test the website for:

* Mobile responsiveness
* Broken links
* Broken buttons
* Cart functionality
* WhatsApp ordering
* Instagram link
* Search
* Product filtering
* Navigation
* Accessibility
* Basic SEO

If something cannot be fully implemented without a backend or external service, build the best working frontend version and clearly explain what needs to be connected later.

FINAL DESIGN DIRECTION

Think of the website as:

Football culture + luxury streetwear + premium sports shop.

The customer should immediately think:

“This is a serious football jersey brand.”

Do not make it look like a school project or a generic online store.

Build ELITE KITS as a brand that could eventually grow into a major football fashion business.
